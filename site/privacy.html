Privacy policy for the Linguva app

Draft. A lawyer has not reviewed this text yet. Points in [brackets] are open.

This policy covers the Shopify app Linguva, which merchants install in their Shopify admin to translate their store. The website has its own privacy policy (German).

Who is responsible

Karina Khrystych, Softwarekey, Havighorster Redder 51, 22115 Hamburg, Germany
Email: shop@softwarekey.de

For store content that Linguva translates on a merchant's behalf, the merchant decides what is translated. [Lawyer: role for store content (processor for the merchant, or controller) and the data processing agreement Linguva offers merchants.]

What Linguva stores

  • The store: its myshopify.com domain, name and Shopify ID, the permissions (access scopes) it granted, its plan, its settings, and when it installed or uninstalled Linguva.
  • Staff members: only the Shopify user ID of the person who took an action (for example who started a translation job or approved a draft), so the store can see who did what. No names and no email addresses.
  • Store content: the texts Linguva reads from Shopify to translate them (products, collections, pages, blog posts, navigation, custom fields, image descriptions and similar), and what Linguva makes from them: drafts, earlier versions, the store's translation memory and glossary. Shopify stays the place where the store's content and published translations live.
  • Access to Shopify: the access token Shopify issues at installation, stored encrypted.
  • Translation keys (Own key plan): the API keys a store adds for DeepL, Microsoft Azure or Google Cloud, stored encrypted and bound to that store. Linguva shows only their last four characters and sends a key only to the service it belongs to. A key the store removes or replaces is deleted at once; copies in backups expire with them.

Linguva does not request access to customers or orders and stores no customer or order data. When Shopify forwards a customer's request to see or delete their data, Linguva records that there is nothing stored. Linguva stores no IP addresses. [Owner and lawyer: what the hosting provider's own request logs contain and how long it keeps them.]

Translation services

Linguva sends store texts for machine translation only after a staff member of the store has agreed to it in Linguva's settings. That agreement can be withdrawn there at any time; from then on no texts are sent.

Linguva uses these translation services in this order: . A text is sent to the next service only when the one before can't translate it (for example, it doesn't offer the language, its monthly limit is used up, or it doesn't answer). A text may therefore have been sent to more than one of these services.

Translation with DeepL

Linguva sends store texts to DeepL SE (Cologne, Germany) for machine translation only after a staff member of the store has agreed to it in Linguva's settings. That agreement can be withdrawn there at any time; from then on no texts are sent. Only the texts to be translated are sent, with a short context to improve the translation (the item's title and the store description entered in Linguva's settings), never data about customers or staff. [Lawyer: DeepL's terms for the API (how long DeepL keeps texts) and the data processing agreement with DeepL.]

Translation with Microsoft Azure

When the store has allowed it, Linguva sends store texts to Microsoft Ireland Operations Ltd. (Dublin, Ireland) for machine translation with Azure AI Translator, in the order described above. Only the texts to be translated are sent: no context (no title, no store description) and never data about customers or staff. Requests go to Microsoft's European endpoint and are processed only in data centres in the EU.Requests may be processed in Microsoft data centres outside the EU. Microsoft states that it doesn't store the texts and doesn't use them for training (No-Trace). [Lawyer: Microsoft Products and Services DPA, transfers, subprocessors.]

Translation with Google Cloud

When the store has allowed it, Linguva sends store texts to Google Cloud EMEA Ltd. (Dublin, Ireland) for machine translation with Cloud Translation, in the order described above. Only the texts to be translated are sent: no context (no title, no store description) and never data about customers or staff. Requests go to Google's European endpoint and are processed only in data centres in the EU.Requests may be processed in Google data centres outside the EU. Google states that it doesn't use the content for anything but providing the service and not for training; texts are held in memory only. [Lawyer: Google Cloud Data Processing Addendum, transfers, subprocessors.]

Stores on the Own key plan

A store on the Own key plan adds its own API key for one or more of these services in Linguva's settings: DeepL (DeepL SE, Cologne, Germany), Microsoft Azure AI Translator (Microsoft Ireland Operations Ltd., Dublin, Ireland) or Google Cloud Translation (Google Cloud EMEA Ltd., Dublin, Ireland). Linguva then sends that store's texts only to the services whose keys the store added, with those keys, in this order: DeepL, then Microsoft Azure, then Google Cloud; a text goes to the next of them only when the one before can't translate it. Linguva never sends that store's texts to the translation services it uses with its own keys, also not when every key of the store is used up or refused. As on every plan, texts are sent only after a staff member of the store has agreed to it in Linguva's settings, and never data about customers or staff.

What each service gets: DeepL gets the texts to be translated with a short context (the item's title and the store description entered in Linguva's settings); Microsoft Azure and Google Cloud get only the texts to be translated, no context. Where they are processed: with DeepL, the key decides the address (keys of DeepL API Free go to api-free.deepl.com, other keys to api.deepl.com); with Microsoft Azure, the store chooses Microsoft's European endpoint (processing only in data centres in the EU) or its global endpoint (processing possibly outside the EU); with Google Cloud, an API key is used, so texts may be processed in Google data centres outside the EU.

The store is the customer of each of these services: its own contract and data processing terms with the service apply to what the service does with the texts, including how long it keeps them; Linguva has no contract with the service for these texts. [Lawyer: roles when the store brings its own contract with the translation service (the service as the store's processor or as a recipient; Linguva as the store's processor for the transmission); whether the data processing agreement Linguva offers merchants must mention it; whether a data processing agreement is available on the tier the store uses (for example DeepL API Free, a free tier) and whether DeepL's terms for it differ from DeepL API Pro on keeping or using texts; transfers outside the EU for Google Cloud's API key (v2) and Microsoft's global endpoint.]

Nothing Linguva translates is published in the store until someone approves it, unless the store has turned on automatic publishing.

Service providers

  • Railway Corporation (USA) hosts the app, its database and its job queue, in its EU West region. [Lawyer: safeguard for the transfer to a US provider, for example the EU-US Data Privacy Framework or standard contractual clauses.]
  • DeepL SE (Germany) translates store texts, as above.
  • Microsoft Ireland Operations Ltd. (Ireland) translates store texts with Azure AI Translator, as above.
  • Google Cloud EMEA Ltd. (Ireland) translates store texts with Cloud Translation, as above.
  • For stores on the Own key plan, the services whose keys the store added (DeepL SE, Germany; Microsoft Ireland Operations Ltd., Ireland; Google Cloud EMEA Ltd., Ireland) translate its texts under the store's own contract with them, as described in "Stores on the Own key plan"; Linguva's own translation services don't.
  • Shopify runs the platform the app works in and bills the plans.

Inside the Shopify admin, the app's pages load Shopify's own scripts, stylesheets and fonts from Shopify's servers, and product images from the store. Linguva uses no analytics, advertising or tracking services and sets no cookies of its own.

Legal bases

[Lawyer: legal bases, for example Art. 6(1)(b) GDPR for providing the app to the merchant and Art. 6(1)(f) GDPR for security and the record of who did what.]

How long data is kept

  • When a store uninstalls Linguva, its access to Shopify (the sessions and the access token) is deleted at once. So are its own translation keys; encrypted copies remain in the database backups until those expire (see the backups item below), and a restored key is not used again until the store checks it.
  • 48 hours after the uninstall, Shopify asks Linguva to erase the store's data. Linguva then deletes everything it holds for the store: settings, content, drafts, versions, translation memory, glossary, translation keys and jobs.
  • Records of Shopify's notifications to the app are deleted after 14 days; records of automatic translation runs after 90 days.
  • The record of who did what is kept without the link to the store. [Lawyer: how long it is kept.] Shopify's privacy requests are kept as evidence that they were answered. [Lawyer: how long.]
  • [Owner: backups of the database at the hosting provider, and how long they are kept.]

Your rights

You have the right to access, correction, deletion, restriction of processing, data portability and to object (Art. 15–21 GDPR). Write to the address above. You can also complain to a data protection authority, for example the Hamburg Commissioner for Data Protection and Freedom of Information.

Datenschutz­erklärung der App Linguva

Entwurf. Dieser Text ist noch nicht anwaltlich geprüft. Punkte in [eckigen Klammern] sind offen.

Diese Erklärung gilt für die Shopify-App Linguva, die Händler in ihrer Shopify-Verwaltung installieren, um ihren Shop zu übersetzen. Für die Website gilt eine eigene Datenschutzerklärung.

Verantwortliche

Karina Khrystych, Softwarekey, Havighorster Redder 51, 22115 Hamburg, Deutschland
E-Mail: shop@softwarekey.de

Bei Shop-Inhalten, die Linguva im Auftrag eines Händlers übersetzt, entscheidet der Händler, was übersetzt wird. [Anwalt: Rolle bei Shop-Inhalten (Auftragsverarbeiter des Händlers oder Verantwortliche) und der Vertrag zur Auftragsverarbeitung, den Linguva Händlern anbietet.]

Was Linguva speichert

  • Der Shop: seine myshopify.com-Adresse, sein Name und seine Shopify-ID, die erteilten Zugriffsrechte, sein Tarif, seine Einstellungen und wann er Linguva installiert oder deinstalliert hat.
  • Mitarbeitende: nur die Shopify-Benutzer-ID der Person, die etwas getan hat (zum Beispiel wer einen Übersetzungsauftrag gestartet oder einen Entwurf freigegeben hat), damit der Shop sieht, wer was getan hat. Keine Namen und keine E-Mail-Adressen.
  • Shop-Inhalte: die Texte, die Linguva aus Shopify liest, um sie zu übersetzen (Produkte, Kollektionen, Seiten, Blogbeiträge, Navigation, benutzerdefinierte Felder, Bildbeschreibungen und Ähnliches), und was Linguva daraus macht: Entwürfe, frühere Fassungen, den Übersetzungsspeicher und das Glossar des Shops. Die Inhalte des Shops und die veröffentlichten Übersetzungen bleiben in Shopify.
  • Zugang zu Shopify: der Zugriffsschlüssel, den Shopify bei der Installation ausstellt, verschlüsselt gespeichert.
  • Übersetzungsschlüssel (Tarif Own key): die API-Schlüssel, die ein Shop für DeepL, Microsoft Azure oder Google Cloud hinterlegt, verschlüsselt gespeichert und an diesen Shop gebunden. Linguva zeigt nur ihre letzten vier Zeichen und sendet einen Schlüssel nur an den Dienst, zu dem er gehört. Ein Schlüssel, den der Shop entfernt oder ersetzt, wird sofort gelöscht; Kopien in Sicherungskopien laufen mit diesen ab.

Linguva verlangt keinen Zugriff auf Kunden oder Bestellungen und speichert keine Kunden- oder Bestelldaten. Leitet Shopify die Anfrage eines Kunden weiter, seine Daten einzusehen oder zu löschen, hält Linguva fest, dass nichts gespeichert ist. Linguva speichert keine IP-Adressen. [Inhaberin und Anwalt: was die eigenen Zugriffsprotokolle des Hosting-Anbieters enthalten und wie lange er sie aufbewahrt.]

Übersetzungsdienste

Linguva sendet Shop-Texte erst dann zur maschinellen Übersetzung, wenn eine Person aus dem Shop in den Einstellungen von Linguva zugestimmt hat. Diese Zustimmung lässt sich dort jederzeit widerrufen; danach werden keine Texte mehr gesendet.

Linguva nutzt diese Übersetzungsdienste in dieser Reihenfolge: . Ein Text geht nur dann an den nächsten Dienst, wenn der vorherige ihn nicht übersetzen kann (zum Beispiel, weil er die Sprache nicht anbietet, sein monatliches Kontingent aufgebraucht ist oder er nicht antwortet). Ein Text kann daher an mehr als einen dieser Dienste gegangen sein.

Übersetzung mit DeepL

Linguva sendet Shop-Texte erst dann an die DeepL SE (Köln, Deutschland) zur maschinellen Übersetzung, wenn eine Person aus dem Shop in den Einstellungen von Linguva zugestimmt hat. Diese Zustimmung lässt sich dort jederzeit widerrufen; danach werden keine Texte mehr gesendet. Gesendet werden nur die zu übersetzenden Texte mit einem kurzen Zusammenhang für eine bessere Übersetzung (der Titel des Eintrags und die Shop-Beschreibung aus den Einstellungen von Linguva), nie Daten über Kunden oder Mitarbeitende. [Anwalt: DeepLs Bedingungen für die Schnittstelle (wie lange DeepL Texte aufbewahrt) und der Vertrag zur Auftragsverarbeitung mit DeepL.]

Übersetzung mit Microsoft Azure

Wenn der Shop es erlaubt hat, sendet Linguva Shop-Texte zur maschinellen Übersetzung mit Azure AI Translator an die Microsoft Ireland Operations Ltd. (Dublin, Irland), in der oben beschriebenen Reihenfolge. Gesendet werden nur die zu übersetzenden Texte: kein Zusammenhang (kein Titel, keine Shop-Beschreibung) und nie Daten über Kunden oder Mitarbeitende. Anfragen gehen an Microsofts europäischen Endpunkt und werden nur in Rechenzentren in der EU verarbeitet.Anfragen können in Rechenzentren von Microsoft außerhalb der EU verarbeitet werden. Microsoft gibt an, die Texte nicht zu speichern und nicht für Training zu nutzen (No-Trace). [Anwalt: Microsoft Products and Services DPA, Übermittlungen, Unterauftragsverarbeiter.]

Übersetzung mit Google Cloud

Wenn der Shop es erlaubt hat, sendet Linguva Shop-Texte zur maschinellen Übersetzung mit Cloud Translation an die Google Cloud EMEA Ltd. (Dublin, Irland), in der oben beschriebenen Reihenfolge. Gesendet werden nur die zu übersetzenden Texte: kein Zusammenhang (kein Titel, keine Shop-Beschreibung) und nie Daten über Kunden oder Mitarbeitende. Anfragen gehen an Googles europäischen Endpunkt und werden nur in Rechenzentren in der EU verarbeitet.Anfragen können in Rechenzentren von Google außerhalb der EU verarbeitet werden. Google gibt an, die Inhalte nur für die Bereitstellung des Dienstes und nicht für Training zu nutzen; die Texte werden nur im Arbeitsspeicher gehalten. [Anwalt: Google Cloud Data Processing Addendum, Übermittlungen, Unterauftragsverarbeiter.]

Shops im Tarif Own key

Ein Shop im Tarif Own key hinterlegt in den Einstellungen von Linguva seinen eigenen API-Schlüssel für einen oder mehrere dieser Dienste: DeepL (DeepL SE, Köln, Deutschland), Microsoft Azure AI Translator (Microsoft Ireland Operations Ltd., Dublin, Irland) oder Google Cloud Translation (Google Cloud EMEA Ltd., Dublin, Irland). Linguva sendet die Texte dieses Shops dann nur an die Dienste, deren Schlüssel der Shop hinterlegt hat, mit diesen Schlüsseln, in dieser Reihenfolge: DeepL, dann Microsoft Azure, dann Google Cloud; ein Text geht nur dann an den nächsten dieser Dienste, wenn der vorherige ihn nicht übersetzen kann. Linguva sendet die Texte dieses Shops nie an die Übersetzungsdienste, die Linguva mit eigenen Schlüsseln nutzt, auch nicht, wenn jeder Schlüssel des Shops aufgebraucht ist oder abgelehnt wird. Wie in jedem Tarif werden Texte erst gesendet, nachdem eine Mitarbeiterin oder ein Mitarbeiter des Shops in den Einstellungen von Linguva zugestimmt hat, und nie Daten über Kunden oder Mitarbeitende.

Was jeder Dienst erhält: DeepL erhält die zu übersetzenden Texte mit einem kurzen Zusammenhang (der Titel des Eintrags und die Shop-Beschreibung aus den Einstellungen von Linguva); Microsoft Azure und Google Cloud erhalten nur die zu übersetzenden Texte, keinen Zusammenhang. Wo sie verarbeitet werden: Bei DeepL entscheidet der Schlüssel über die Adresse (Schlüssel von DeepL API Free gehen an api-free.deepl.com, andere an api.deepl.com); bei Microsoft Azure wählt der Shop den europäischen Endpunkt von Microsoft (Verarbeitung nur in Rechenzentren in der EU) oder den globalen Endpunkt (Verarbeitung möglicherweise außerhalb der EU); bei Google Cloud wird ein API-Schlüssel genutzt, Texte können daher in Rechenzentren von Google außerhalb der EU verarbeitet werden.

Der Shop ist Kunde jedes dieser Dienste: Für das, was der Dienst mit den Texten macht, auch wie lange er sie aufbewahrt, gelten der eigene Vertrag und die Bedingungen zur Datenverarbeitung des Shops mit dem Dienst; Linguva hat für diese Texte keinen Vertrag mit dem Dienst. [Anwalt: Rollen, wenn der Shop einen eigenen Vertrag mit dem Übersetzungsdienst mitbringt (Dienst als Auftragsverarbeiter des Shops oder als Empfänger; Linguva als Auftragsverarbeiter des Shops für die Übermittlung); ob der Auftragsverarbeitungsvertrag, den Linguva Händlern anbietet, das nennen muss; ob auf der Stufe, die der Shop nutzt (etwa DeepL API Free, eine kostenlose Stufe), ein Auftragsverarbeitungsvertrag verfügbar ist und ob DeepLs Bedingungen dafür beim Aufbewahren oder Nutzen von Texten von DeepL API Pro abweichen; Übermittlungen außerhalb der EU beim API-Schlüssel von Google Cloud (v2) und beim globalen Endpunkt von Microsoft.]

Was Linguva übersetzt, erscheint erst im Shop, wenn jemand es freigegeben hat, außer der Shop hat das automatische Veröffentlichen eingeschaltet.
